# Examples

Файлы для проверки импорта Excel (`POST /api/plan/import`) и экспорта (`GET /api/plan/export`).

Колонки в обоих файлах:

`задача`, `описание`, `исполнитель`, `длительность`, `предшественники`

- `sample-plan.xlsx` — основной пример: план разработки этого продукта. Предшественники — **имена задач** через запятую (`Дизайн API, Схема БД`).
- `random-import.xlsx` — запасной набор (другой домен). Предшественники — **номера строк** через запятую (`2, 3`).

Дат в файлах нет: CPM считает старт и финиш от `project_start`.
